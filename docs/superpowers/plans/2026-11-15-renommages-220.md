# Renommages groupés de la 12.0 (#220) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Donner aux noms publics fautifs leur bon nom dès la 11.x, et retirer les anciens sur `release/12.0.0`.

**Architecture:** Deux PR. La première, sur `main`, renomme les fichiers, laisse les anciens chemins en alias `pub use`, ajoute `PayloadType::NatDiscovery` en constante associée et déprécie la variante. La seconde, sur `release/12.0.0`, retire les alias et renomme les variantes sur place.

**Tech Stack:** Rust 2024, MSRV 1.88, `cargo semver-checks`, GitHub CLI.

**Spec:** `docs/superpowers/specs/2026-11-15-renommages-220-design.md`

## Global Constraints

- Aucune rupture sur `main` : `cargo semver-checks` n'y demande aucune montée de version.
- Aucun discriminant d'enum ne bouge ; aucune étiquette, aucun JSON ne change.
- `release/12.0.0` garde `version = "12.0.0"` (Cargo.toml et quatre lock).
- Commentaires, commits et CHANGELOG en français sans accents ; `MIGRATION-12.md`, PR et issues en français accentué.
- Commits `type(scope): resume (#220)`, terminés par `Co-Authored-By: Claude Fable 5.2 <noreply@anthropic.com>`.
- Avant de pousser : `cargo fmt --check`, `cargo clippy --all-targets -- -D warnings` (stable), `cargo +1.88 check --all-targets`, `cargo test`, `cargo doc --no-deps`, `cargo +nightly fuzz build`, build de `tools/lab` et `benches`.
- Fusion : `gh pr merge <n> --merge --delete-branch` quand les jobs GitHub Actions sont verts (FOSSA « License Compliance » reste rouge, #241).
- Pas de tag, pas de publication.

## Review Focus

- Un appelant externe qui écrit encore `…::copt::CotpHeader` ou `…::mac_addres::MacAddress(octets)` en 11.x compile sans changement (tâche 1, test d'alias).
- Un `match` externe sur `PayloadType::NatDetection` en 11.x compile encore, avec un avertissement (tâche 2).
